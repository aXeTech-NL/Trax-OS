# Product design documentation

- [Brand Identity and Design System](DESIGN_SYSTEM.md)

The design system follows the product architecture:

- Personal mode provides simple journey ownership and sharing;
- Agency mode adds a portfolio, travel parties and a Roles & Permissions console without forking the product;
- desktop and large tablet form the primary journey-planning cockpit;
- mobile is a fully functional, offline-first travel companion;
- manual, Atlas and external-agent changes use the same review model;
- medium-risk actions expose clear confirmation and undo;
- high-risk actions show an exact preview and require explicit approval;
- device-only documents show replica and transfer state without implying cloud content storage;
- audience and effective-access explanations prevent accidental cross-party sharing;
- V1 agent research is shown as cited, uncertain suggestions that require review before adoption.

Brand and trademark usage rules remain in [`BRANDING.md`](../../BRANDING.md) and [`TRADEMARKS.md`](../../TRADEMARKS.md).
